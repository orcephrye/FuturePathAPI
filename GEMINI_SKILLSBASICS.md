# Skill System Summary

## Core Roll
**1d20 + Skill Die + Ability Modifier + Miscellaneous Modifiers** vs **Difficulty Class (DC)**.

## Skill Types
*   **Favored:** Costs 1 point per rank (Non-favored costs 2). Gaining a Favored Skill (via Path or Class) grants 1 free Skill Point specifically for that skill.
*   **Natural:** Usable at Rank 0 (Untrained). Roll: `d20 + Ability Mod + Misc Mods`.
*   **Unnatural:** Requires at least Rank 1 (Trained) to use.
*   **Rank Dependent:** Skill Rank predetermines maximum outcome or static effects (Athletics, Craft, Perform, Language, Medical).

## Ranks & Competency
- **Max Rank:** `1/2 Character Level` (round up). *Exception:* Language max rank is 10 and not bound by character level limit.
- **Competency Bonus:** Added as a static Misc Mod (+0 to +5).
- **Competency DC Requirements:** GM can assign a Competency requirement to a DC. DC adjusts by +/- 3 (or +4 for lower competency) per level difference.
  - **Unexperienced (Rank 0-1):** +0 Bonus | Die: 0 (Rank 0), 1d2 (Rank 1)
  - **Novice (Rank 2-3):** +1 Bonus | Die: 1d2+1 (Rank 2), 1d4+1 (Rank 3)
  - **Intermediate (Rank 4-5):** +2 Bonus | Die: 1d4+2 (Rank 4), 1d6+2 (Rank 5)
  - **Competent (Rank 6-7):** +3 Bonus | Die: 1d6+3 (Rank 6), 1d8+3 (Rank 7)
  - **Expert (Rank 8-9):** +4 Bonus | Die: 1d8+4 (Rank 8), 1d10+4 (Rank 9)
  - **Master (Rank 10):** +5 Bonus | Die: 1d10+5

## Rank Dependent Skills
*   **Athletics:** Increases base movement speed and carrying capacity.
*   **Craft:** Determines Masterwork capabilities.
*   **Perform:** Determines maximum ISK earned from performances.
*   **Language:** Determines fluency and number of languages known. Always Favored.
*   **Medical:** Determines number of Hit Die used for health recovery.

## Using Skills & Time Rules
*   **Time & Rushing:** Base time 1–2 minutes (or 3s/round out-of-combat). Rushing in combat/danger adds +5 to DC.
*   **Taking 10/20:** Takes 10 or 20 minutes of in-game time. Replaces d20 roll with 10 or 20 (`10/20 + Skill Rank + Competency Level + Misc Mods`). Requires no threat/distraction and no penalty for failure.
*   **Aiding Another:** Helper must be able to perform skill. Aided character gains Advantage equal to # of helpers, plus up to 3 re-rolls for failures.
*   **Dividing Tasks:** Helpers share workload for speed; all must succeed for task completion. Cannot be combined with Taking 10/20.
*   **Cooperative Checks:** All characters roll individually; only one needs to succeed (e.g., Perception searches).
*   **Opposed Checks:** Highest roll wins. Ties go to the character with the higher key Ability Score (re-roll if tied again).
*   **Profession Kits:** Default kit has 20 uses. Failed checks still consume a use.
*   **Skill Synergy (Optional):** When two skills apply, roll both checks and take the higher result.

## Ability Checks & Saving Throws
*   **Standard Roll:** `d20 + Ability Mod`.
*   **With Ability Affinity:** `d20 + Ability Die + Advantage Die`.
*   **Aiding:** Helper requires at least score 10 in that Ability. Cannot aid Saving Throws. Taking 10/20 does not apply.

## Skill List by Ability
*   **STR:** Athletics, Intimidate, Escape Artist
*   **DEX:** Acrobatics, Escape Artist, Pilot, Ride, Sleight of Hand, Stealth
*   **CON:** None
*   **INT:** Computer Use, Craft, Decipher Script, Demolitions, Disable Device, Knowledge, Study, Bluff
*   **WIS:** Perception, Sense Motive, Survival, Medical, Diplomacy, Demolitions, Handle Animal
*   **CHA:** Bluff, Diplomacy, Disguise, Handle Animal, Intimidate, Perform
