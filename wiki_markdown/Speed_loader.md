This is a Weapon Accessory. To learn more about Weapons go
[here](Weapons "here"){.wikilink}.

If a Character is out of magazines in combat and needs to reload them,
then this decreases the time it takes. A single magazine normally holds
10 rounds. A speed loader reduces it to one round. However, a speed
loader can only load two magazines before it needs to be reloaded.

The crafting bonus can make the speed loader hold more ammo, allowing it
to load more magazines. Each +1 craft bonus provides 1 more magazine
that the speed loader can load. A speed loader can only load 1 magazine
per round.

Benefit
: This loads ammunition back into magazines both in and out of combat.
  And can do so automatically in a single round of combat or 3 seconds
  per magazine.
