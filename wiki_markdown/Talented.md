**Prerequisites**: Affinity Die 1d10

**Benefits**: This allows a single talent from a Class to be affected
not by the Class level but instead by the Character level. Any attribute
of the talent that is stated to be affected by level now means the level
of the Character instead of the Advanced Class.

**Normal**: Normally, all talent\'s attributes that are affected by the
level of the Class itself, not the total Character level.

**Special**: This can be taken up to two times.
