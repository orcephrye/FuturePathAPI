## Skill Description Format {#skill_description_format}

Skill descriptions adhere to the following guidelines.

`<u>`{=html}Skill Name`</u>`{=html}: The skill name line includes (in
addition to the name of the skill) the following information.

`<u>`{=html}Ability`</u>`{=html}: The ability whose modifier is applied
to the skill die level. Some Skills have two abilities associated with
them. In this case, the Player chooses which Ability to use when using
the Skill. The Skill descriptions will explain this further.

`<u>`{=html}Type`</u>`{=html}: Whether or not the skill is Natural,
Unnatural, or Rank Dependent.

`<u>`{=html}Description`</u>`{=html}: The skill name line is followed by
a general description of what using the skill represents.

`<u>`{=html}Check`</u>`{=html}: What a character can do with a
successful skill check and the check\'s Difficulty Class (DC).

`<u>`{=html}Action`</u>`{=html}: The type of action using the skill
requires, or the amount of time required for a check.

`<u>`{=html}Try Again`</u>`{=html}: Any conditions that apply to
successive attempts to use the skill successfully. If the skill doesn\'t
allow you to attempt the same task more than once, or if failure carries
an inherent penalty (such as with the Climb skill), you can\'t take 20.
If this paragraph is omitted, the skill can be retried without any
inherent penalty other than the additional time required.

`<u>`{=html}Special`</u>`{=html}: Any extra facts that apply to the
skill, such as special effects deriving from its use or bonuses that
certain characters receive because of class, feat choices, or race.

## Skill Types {#skill_types}

For the basic rules of using and gaining skills, visit the [Skills
Basics](SkillsBasics "Skills Basics"){.wikilink} page.

Natural
: This means that the skill doesn\'t need to be \'Trained\' first before
  a Character can use it. It implies that the skill is a common, simple
  task that just about anyone can perform at least on a basic level.

<!-- -->

Unnatural
: This means that the skill cannot be used until a Skill Point is spent
  so that it is \'Trained\'. It has to be taught and is not something a
  Character can simply do or just know. It implies that knowledge and
  training were provided to perform the Skill\'s actions.

<!-- -->

Rank Dependent
: This means that the outcome of a successful check is somewhat
  predetermined by the Rank of the Skill. A Character cannot be more
  successful at this action than what is predetermined for whatever Rank
  they have in that Skill. Aside from this, these skills function just
  like the \'Unnatural\' skills.

## Feat Based Skills {#feat_based_skills}

These are special skills that are only available through a Feat, which
some classes provide or can be gained by leveling. These skills do not
follow the normal rules, especially when it comes to Rank limits.

## Skill Like Abilities {#skill_like_abilities}

These are abilities that a Character has that level naturally up with
the Character, and the Player doesn\'t need to spend Skill Points on
them. They function like Skills but do not require Skill Points to
improve them.
