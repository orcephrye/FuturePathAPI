**Prerequisites**: Dexterity 13, Dodge, Mobility, Affinity +4

**Benefit**: This Feat must be declared before the Character takes
his/her turn. This allows a Character too also move within there same
turn. They can choose to move before or after an attack or even both. As
long as the move action is the Character\'s base speed. The Character
can only do this once between rests. And requires full rest to recover.
