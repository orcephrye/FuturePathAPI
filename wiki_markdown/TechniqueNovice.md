**Prerequisites**: A Class that supports the use of Techniques

**Benefits**: A Character can use Level 0 Techniques infinitely.

**Normal**: A Character cannot infinitely use level 0 techniques unless
they take this feat.

**Special**: Combat and Advanced Combat Techniques are considered level
0 but can be used infinitely. This only applies to class-specific
techniques.
