These are Characters and their corresponding Character Sheets
pre-filled.

## Why use Starter/Premade Character Sheets? {#why_use_starterpremade_character_sheets}

1.  If you want to get things started quickly.
2.  If you are unsure of how to build a Character but want to start
    playing the game. You don\'t need to learn everything all at once,
    so why not skip the Character creation step?
3.  If you are the GM and you wish to provide some starter options to
    players to help ease them into game play.

## How to use Starter/Premade Character Sheets? {#how_to_use_starterpremade_character_sheets}

- Feel free to make your own edits. These are not official or set in
  stone. Change the name, or some starter items, etc\...
- When leveling, there is no need to follow the advice provided. That
  advice is simply there to help guide new players, and it\'s not a
  requirement or rule.
- Note that the PDFs provided are form-fillable just like the standard
  PDF. Feel free to edit it before printing.

## Starter vs Premade {#starter_vs_premade}

- **Starters** all start at level 1. They provide some advice on choices
  during the first couple of levels.
- **Premade** start at any level. And provide little or no guidance on
  leveling choices.
