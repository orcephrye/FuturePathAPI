Ram is a function of a Spaceship. Space Ships and other functions can be
found [here](Space_Ships#Officer.2FShip_Functions "here"){.wikilink}.
This allows a ship to Ram into another ship in such a way that it does
damage to the target ship with little damage to the ramming ship.

## Description

If in Short range and a successful
[Pursue/Intercept](Pursue/Intercept "Pursue/Intercept"){.wikilink} check
was done the last round, then this round the Pilot can choose to Ram the
enemy vessel. Roll a percentile check. If above 50%, both ships take
Battle Damage. If below 50%, then only the enemy ship takes Battle
Damage. If your ship takes Battle Damage, the crew is ready for impact
and is not shaken. The DC is simply 7 to repair the damage. While the
enemy ship, you have to roll for Battle Damage, re-roll 7s.
