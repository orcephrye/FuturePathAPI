Grapple is a function of a spaceship. Space Ships and other functions
can be found
[here](Space_Ships#Officer.2FShip_Functions "here"){.wikilink}. However,
it is also a combat technique noted in the
[Combat](Combat "Combat"){.wikilink} section. Please go there if you
want to review the Grapple Technique for character combat. Grapple
allows ships to hold or even move other ships.

### Description

Grapple can be as crude as a physical spear or a clamp-like projectile
that hooks onto another object in hopes of reeling it in. However, these
crude methods allow control of an object in only one direction, and only
if the ship is heavier than the target object. Other, more advanced
methods, such as the Tractor beam, allow for a range of motion and can
help avoid feedback, ensuring that the grappled object cannot, in turn,
move the ship. These are obviously more advanced.

In order to attempt a Grapple, the ship must first be within Reach.
Reach is determined by the Grappler\'s type. Pilots must also have
performed a successful pilot check against the target. The Pilot action
can be anything so long as it was successful. The Engineer then rolls
against the target ship\'s Tracking DC. If successful, the enemy vessel
cannot apply the Engines Mod to their Tracking DC. The only Pilot check
that the Grappled ship can do is to escape the Grapple, which is DC 10 +
Grappler Class Level + Engines Mod. The ship doing the Grapple cannot
**Ram** the grappled ship, but a **Ram** action is automatically
successful against a Grappled enemy ship. Any **Ram** action
successfully done against either ship instantly removes the Grapple. A
Grappled ship no longer gains the small size defense that keeps ships of
4 sizes or bigger from being able to fire.

Higher class levels (ie, Masterworked devices) by default provide a
bonus equal to their class level to both the roll to Grapple a ship and
the DC to escape the Grapple. However, different devices may have
additional bonuses.

A Ship smaller than Small cannot have a Grappler.

: **Associated Ship Attribute**: Engines
: **Associated Ship Position**: Engineer
: **Roll**: d20 + Engines Mod + Class Level
: **Price**: The price can vary widely depending on the type of Grapple
  system. And then there is a price increase based on the Grappler\'s
  size.

The bonus cost based on size is:

- Small: No Bonus
- Medium: +\$100,000
- Large: +\$250,000
- Huge: +\$1,000,000
- Gargantuan: +\$5,000,000
- Colossal: +\$20,000,000

## Grapple Types {#grapple_types}

**Robotic Arm**:

: Description: This is an extendable arm. Since it\'s such a simple
  thing, the size bonus is halved.
: Tech: 1
: Reach: Short
: Price: \$50,000
: Restrictions: Can only Grapple ships 3 sizes small or smaller.
: Class Level Bonus: Each class level provides an additional arm to be
  able to grapple multiple ships.

**Magnetic Harpoon**:

: Description: This device attempts to both puncture and/or magnetically
  seal itself to an object. Used mostly for scrap, this can quickly
  launch itself at an object and recoil back. Since it\'s such a simple
  object, the size bonus to the price is halved.
: Tech: 1
: Reach: Small
: Price: \$75,000
: Class Level Bonus: At Class level 3, this gains a Reach bonus that
  extends to Medium.

**Grappling Clamps**:

: Description: This device attempts to shoot out one or more clamps to
  grab onto objects. Seen as a more advanced version of a Magnetic
  Harpoon, as it is, in some ways, a combination of both the Harpoon and
  the Robotic Arm, and as a result, this system is more robust. It is
  capable of grappling multiple targets. Although not simultaneously,
  the ship can perform the Grapple function on another object before the
  first object is released. This can also be upgraded so that the clamps
  have their own retro thrusters so it can aim and move targets more
  effectively.
: Tech: 1-2
: Reach: Small
: Price: \$150,000/Tech 2 \$225,000
: Misc: This provides a +1 to the DC for escaping the Grapple. The Tech
  2 version of the grappling clamps has a +1 bonus to Grapple and a +2
  bonus to the DC due to the retro thrusters.

**Multi-Positional Laser Tractor**:

: Description: The first attempt a \'true\' Tractor beam. This system
  relays on multi positions on the ship pointing a single target. There
  are three points on the ship, and each point shoots a non-harmful
  laser at the target object. Each point exerts pressure on the object,
  and when all 3 act together, 3D motion can occur.
: Tech: 2-3
: Reach: Medium
: Restrictions: This can only be installed on Large or bigger ship
  sizes.
: Price: \$225,000 / Tech 3 \$400,000
: Misc: This gains a +2 DC to escaping the Grapple because of its
  ability to move the ship in all directions. The Tech 3 version of this
  system has an extra range increment for improved focused laser
  technology.

**Wide Angle Tractor Beam**:

: Description: The first time a tractor beam can come from a single
  source. The ship no longer needs to be Huge or even Large to
  accommodate the system.
: Tech: 3
: Reach: Medium
: Restrictions: None
: Price: \$600,000
: Class Level Bonus: Provides +2 for Grapple checks and to DC for each
  Class level instead of +1.

**Focused Tractor Beam**:

: Description: Considered by most to be the height of Tractor Beam
  technology. This Grapple system can take control of most any ship. It
  also has one of the highest range increments.
: Tech 3 - 4
: Reach: Medium
: Restrictions: None
: Price: \$2,500,000 / Tech 4 \$6,000,000
: Misc: Tech 4 version has an improved range increment of Large.
: Class Level Bonus: Provides +2 for Grapple checks and to DC at class
  levels 1, 3, and 5. A Class Level 2, this gains a second Beam to
  target a second ship. At Class Level 4, this gains a range improvement
  at Tech 3 to Large and at Tech 4 to Huge, making it the longest-range
  system.

**Quantum Wave Field**:

: Description: Considered to be part of most space pirates\' worst
  nightmares, this device is rare and extremely advanced. It is designed
  to use Sub-space FTL technology to create millions of quantum bubbles
  around a ship. The object is forced to the center of this wave field.
  The center is controlled by the ship. that deploys this grapple. It
  was designed to \'safely\' pull a ship out of warp. It can be used to
  hold a ship and move it around. Many advanced Tech 3+ or Tech 4
  civilizations consider it illegal to give this type of technology to
  lower-tech civilizations. The procure difficulty is 4. Also, this
  device can grapple a ship out of an FTL move.
: Tech 4
: Reach: Small
: Price: \$35,000,000 / Procure Diff 4
: Misc: This acts like a Warp Disruptor as well. It cannot disrupt warp
  fields if it is actively grappling with another target. +3 to Grapple
  and to the DC.
: Class Level Bonus: Provides +2 for Grapple checks and to DC for each
  Class level instead of +1. At Class Level 3 it gains a range of
  Medium.
