**Prerequisite**: N/A

**Benefit**: The character can now able too gain advantage when using
off hand weapons. This only applies if the character is proficient in
the weapon to begin with. They do not simply get advantage because the
weapon is in there off hand. Also this only counts for valid off hand
weapons. IE: Any weapon that is not considered \'heavy\' which by
default means any Level 7 or higher weapon.

**Normal**: Normally a Character can use a second weapon in there off
hand but they gain no advantages for using it. There are additional
penalties depending on if the weapon is ranged or melee. However this
feet only deals with the no advantage penalty.
