You are a Mutant that is more powerful than normal. Learn more about
Mutations by going to [here](Mutations "here"){.wikilink}.

**Prerequisites**: Character must already be a
[Mutant](Mutations "Mutant"){.wikilink} or
[Psion](Psionics "Psion"){.wikilink}.

**Benefit**: The Character can spend their level + 6 in MP.

**Note**: For Psions this is Character level + 5.

**Note**: This is a plus added to the base +3. So if you are a [Human
Mutant](Species#(Sub-Species)_Human_Mutant "Human Mutant"){.wikilink}
this would be Character Level + 7.

**Normal**: Without this feat, a Character is limited to Character
level + 3 MP.

**Special**: -
