For a full list of Feats, go to the [[Feats|Feats]] page.

'''Prerequisites''': A Class that supports the use of Techniques and the Feat [[TechniqueNovice|Technique Novice]]. 

'''Benefits''':  The Player picks a Technique (s) that the Character can already use, and now that Technique can be performed as a Bonus Action if the Player chooses. When using a Class-specific Technique, if that Technique is part of the same Technique class as the Technique (s) picked by this feat, then gain a Bonus Technique Action that includes all the Techniques Quickened by this feat. Every time the Character levels up, they can change which Techniques are Quickened. All Level 0 Techniques are now considered Quickened.

'''Normal''': Techniques normally do not grant Bonus Actions.

'''Special''': 
# If the Character has the [[TechniqueAdvance|Technique, Advance]] feat then if the Character can choose '''two''' Techniques that the Character can now choose to Quicken. 
# If the Character has the [[TechniqueMaster|Technique, Master]] feat then if the Character can choose '''three''' Techniques that the Character can now choose to Quicken. 
# This Feat can be taken multiple times for different Techniques.
