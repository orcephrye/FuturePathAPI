You are a Mutant that is more powerful than normal. Learn more about Mutations by going to [[Mutations|here]].

'''Prerequisites''': Character must already be a [[Mutations|Mutant]] or [[Psionics|Psion]].

'''Benefit''': The Character can spend their level + 6 in MP.

'''Note''': For Psions this is Character level + 5.

'''Note''': This is a plus added to the base +3. So if you are a [[Species#(Sub-Species)_Human_Mutant|Human Mutant]] this would be Character Level + 7.

'''Normal''': Without this feat, a Character is limited to Character level + 3 MP.

'''Special''': -
